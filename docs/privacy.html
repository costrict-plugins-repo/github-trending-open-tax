Privacy Policy

Last updated: April 3, 2026

The short version: Open Tax runs entirely on your local machine. We do not collect, store, transmit, or have access to any of your data. Period.

What Open Tax Is

Open Tax is a free, open-source plugin for Claude Code that assists with US federal tax preparation. It is distributed as source code via GitHub and runs locally within your Claude Code environment.

Data Collection

Open Tax does not collect any data. Specifically:

  • No personal information is collected, stored, or transmitted
  • No tax documents, financial data, or computed results leave your machine
  • No analytics, telemetry, or usage tracking of any kind
  • No cookies, local storage, or browser fingerprinting
  • No network requests are made by the plugin itself
  • No accounts are required to use Open Tax

Where Your Data Lives

All tax documents, parsed data, computed results, and export files are stored locally in the workspace/ directory on your machine. This directory is gitignored by default to prevent accidental commits of personal data.

Third-Party Services

Open Tax itself makes no calls to external services. However:

  • Claude Code / Claude API — When you use Open Tax through Claude Code, your prompts and conversations are processed by Anthropic's API according to Anthropic's Privacy Policy. Open Tax does not control this.
  • GitHub — The source code is hosted on GitHub. Downloading or cloning the repository is subject to GitHub's Privacy Statement.

Open Source Transparency

Open Tax is fully open source under the MIT License. You can inspect every line of code at github.com/tugberkgoc/open-tax to verify these privacy claims for yourself. The plugin contains no obfuscated code, no hidden network calls, and no data exfiltration of any kind.

Children's Privacy

Open Tax does not knowingly collect any information from anyone, including children under 13.

Changes to This Policy

If this privacy policy changes, updates will be posted on this page with a revised date. Since Open Tax collects no data, meaningful changes are unlikely.

Contact

For questions about this privacy policy, open an issue on GitHub.
